# 公益法人会計-Excel

Excel / VBA で構築する公益法人会計システム。  
仕訳帳を基点に、各種財務諸表を自動生成する設計。

---

## 概要

本システムは、公益法人会計基準に基づき、
仕訳データから以下の帳票を自動生成することを目的とした
Excelベースの会計システムです。

年度単位でファイルを更新しながら運用する設計としています。

自分用に作ったもののため、未実装の部分は多いです。

---

## 対応機能

- 仕訳帳から以下を自動生成
  - 総勘定元帳・補助元帳
  - 残高試算表
  - 貸借対照表
  - 活動計算書・活動計算書の注記(1)~(3)
- 補助科目に対応（会計区分（公1、公2、等）は補助科目に紐づきます）
- 純資産区分（一般／指定）に対応
- 勘定科目コードマスターを実装
- 補助科目コードマスターを実装
- 財務諸表マスタのを実装
- 年度ごとにファイルを更新する運用設計

---

## 設計方針

- 仕訳帳を唯一の入力データとする
- コード体系（勘定科目・補助科目）を基盤とした集計構造
- Excel関数＋VBAによる自動集計
- 表示ロジックとデータ構造の分離を志向

---

## 現在の非対応事項

- キャッシュフロー計算書
- 内部取引等消去
- 共通費の配賦
- 法人税

---

## 動作環境

- Microsoft Excel（マクロ有効ブック）
